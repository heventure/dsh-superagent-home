## 运行/依赖

```bash
node evals/tools/run_evidence.mjs <会话记录路径>/session.v4.jsonl.zstd
```

- 会话记录为 zstd 压缩 JSONL；工具使用 Node 内置 `zlib.zstdDecompressSync`（Node ≥22），无需第三方依赖。
- `tools/redact.mjs` 在写入 `results/<version>/runs/` 前做脱敏。
