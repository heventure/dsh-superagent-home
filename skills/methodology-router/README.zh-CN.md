# methodology-router

让 Agent 在复杂、陌生或跨领域的任务中，先选对方法，再执行和核查；简单任务不打扰。

## 做什么

- 识别问题的目标、事实、约束、成功标准和主要风险。
- 构建精简的知识地图，比较候选方法的适用前提、所需输入和局限，选最简单够用的方法。
- 执行时区分已验证事实、假设、估计和未知；执行后核查方法和结果。
- 按用户需要决定讲解深度。

## 何时触发

- 复杂、陌生或跨领域的任务。
- 用户只给目标，没给方法。
- 多种方法都可能适用。
- 错误假设的代价高。

## 何时跳过

- 简单明确的任务。
- 用户已经指定了合适的方法（直接用，不重选；只有方法明显不适用时才简短提示）。
- 再分析也不会改变执行的情况。

## 学习深度

| 模式 | 触发信号 | 行为 |
| --- | --- | --- |
| `execute` | “直接做”“别讲原理”、低风险 | 给结果和下一步，几乎不解释。高风险操作仍会说明关键风险。 |
| `guided`（默认） | 没有明确信号 | 边做边解释关键选择及依据。 |
| `deep` | “教我”“我想学会判断” | 讲原理、适用边界、常见误区，以及如何自行验证。 |

## 安装

Skill 目录是 `skills/methodology-router/`。安装到运行账号的 Skill 目录：

```bash
mkdir -p "$HOME/.agents/skills"
cp -R skills/methodology-router "$HOME/.agents/skills/methodology-router"
```

安装后应能在新会话中被发现（Skill 列表里出现 `methodology-router`）。

## 卸载

```bash
rm -rf "$HOME/.agents/skills/methodology-router"
```

只删除本 Skill 的目录，不影响其他 Skill。

## 已知局限

- 触发依赖 `description` 与用户提示词的语义匹配，不是关键词规则；匹配结果会随模型和提示词变化。
- 评测样本量小，见 `evals/`；结果不能外推到其他模型或领域。
- 评分由作者本人完成，存在偏差。
- 未覆盖多轮长对话中的 Skill 持续效果，也未覆盖需要联网核实术语的场景（取决于运行环境是否有查证工具）。
