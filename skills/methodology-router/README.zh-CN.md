# methodology-router

让 Agent 在复杂、陌生或跨领域的任务中，先选对方法，再执行和核查；简单任务不打扰。

## 做什么

- 识别问题的目标、事实、约束、成功标准和主要风险。
- 构建精简的知识地图，比较候选方法的适用前提、所需输入和局限，选最简单够用的方法。
- 执行时区分已验证事实、假设、估计和未知；执行后核查方法和结果。
- 按用户需要决定讲解深度。

## 何时触发

- 复杂、陌生或跨领域的任务。
- 用户只给目标，没给方法。
- 多种方法都可能适用。
- 错误假设的代价高。

## 何时跳过

- 简单明确的任务。
- 用户已经指定了合适的方法（直接用，不重选；只有方法明显不适用时才简短提示）。
- 再分析也不会改变执行的情况。

## 学习深度

| 模式 | 触发信号 | 行为 |
| --- | --- | --- |
| `execute` | “直接做”“别讲原理”、低风险 | 给结果和下一步，几乎不解释。高风险操作仍会说明关键风险。 |
| `guided`（默认） | 没有明确信号 | 边做边解释关键选择及依据。 |
| `deep` | “教我”“我想学会判断” | 讲原理、适用边界、常见误区，以及如何自行验证。 |

## 安装

运行时只需要 `SKILL.md`。不要把 `evals/` 一起装上：其中有评分标准和预期答案，模型加载 Skill 后可能读到它们，评测就失效了。

```bash
mkdir -p "$HOME/.agents/skills/methodology-router"
cp skills/methodology-router/SKILL.md "$HOME/.agents/skills/methodology-router/SKILL.md"
```

安装后应能在新会话中被发现（Skill 列表里出现 `methodology-router`）。

## 卸载

```bash
rm -rf "$HOME/.agents/skills/methodology-router"
```

只删除本 Skill 的目录，不影响其他 Skill。

## 已知局限

- 触发依赖 `description` 与用户提示词的语义匹配，不是关键词规则；匹配结果会随模型和提示词变化。
- 评测样本量小，见 `evals/`；结果不能外推到其他模型或领域。
- 评分由作者本人完成，存在偏差。
- 未覆盖多轮长对话中的 Skill 持续效果，也未覆盖需要联网核实术语的场景（取决于运行环境是否有查证工具）。
- 评测样本小、单模型、评分者即作者；判定按内容（加载≠行为通过）。v4 触发/跳过有历史门槛证据（T 14/14、N 12/12、S4 2/2，扩展 H+S+T 20/25），但最新正文 v5 的行为评测存在已知失败（H3、S2-1/2、S6-1/2、S5-1/2 失败/部分；D3 仅行为），不宣称全部验收通过。存在路径级污染记录与无干净记录的项（T12/N06/N13）；控制组为安装前旧对照，非同期。详见 `evals/results/v4`、`evals/results/v5`。
